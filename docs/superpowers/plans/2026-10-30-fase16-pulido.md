`// MUTACION TEMPORAL`. Correr la suite de la tarea. **Si pasa en verde, o se cierra el agujero —con

`<body>`; partir el dato en trozos; y el `.value` que escriba la limpieza de un `useEffect`.

### Las cinco formas de que un test no pueda fallar

1. **Autorreferencial** — comparar la salida contra la misma función que la produce.
2. **Premisa destruida** — el código bajo prueba borra el borde que el test venía a ejercitar.
3. **Montado en el caso ciego** — fijar algo en el único escenario donde la distinción no existe.
4. **Verde por casualidad ortográfica** — `not.toContain('0%')` **pasa sobre un `100%`**.
5. **El fixture habla el idioma del código y no el del contrato.**

Para afirmar que algo **NO** se dice, **montá dos veces** y compará el resto **por igualdad**.

- [ ] **Step 2: Implementar `lib/sesion-caducada.ts`**

```ts
import { ErrorDeApi } from './cliente';
import { destinoDeLoginDesde } from './destino-de-login';

/**
 * A DONDE MANDAR A QUIEN SE LE CADUCO LA SESION AL GUARDAR, o `null` si el
 * error no es eso.
 *
 * Pura y aparte de `query.tsx` para probarla sin montar el proveedor. El slug
 * es el primer segmento de la ruta: todo lo que escribe cuelga de `/[slug]`.
 * Sin slug, o ya en el login, no hay a donde mandar.
 */
export function destinoSiCaducoLaSesion(
  error: unknown,
  ubicacion: { pathname: string; search: string },
): string | null {
  if (!(error instanceof ErrorDeApi) || !error.esSesionCaducada) return null;

  const [, slug = '', seccion] = ubicacion.pathname.split('/');
  if (slug === '' || seccion === 'login') return null;

  return destinoDeLoginDesde(ubicacion.pathname, ubicacion.search, slug);
}
```

```tsx
import { MutationCache, QueryClient, QueryClientProvider } from '@tanstack/react-query';
import { useState, type ReactNode } from 'react';
import { ErrorDeApi } from './cliente';
import { destinoSiCaducoLaSesion } from './sesion-caducada';

/**
 * El cliente de datos de la app.
 *
 * UNA ESCRITURA CON 401 MANDA AL LOGIN, desde aqui y para todas. Las lecturas
 * no: cada pantalla ya lo resuelve con su propio aviso. Antes de esto, de
 * veintiuna pantallas que escriben solo una mandaba al login; las demas
 * enseñaban «Unauthorized».
 *
 * `window.location.assign` y no el router: la recarga entera tira esta cache, y
 * con ella cualquier dato de la sesion que vencio. `saliendo` evita navegar dos
 * veces si fallan dos escrituras juntas. `ir` se inyecta solo para los tests.
 */
export function crearClienteDeDatos(
  ir: (destino: string) => void = (destino) => window.location.assign(destino),
): QueryClient {
  let saliendo = false;

  return new QueryClient({
    mutationCache: new MutationCache({
      onError: (error) => {
        if (saliendo) return;
        const destino = destinoSiCaducoLaSesion(error, window.location);
        if (destino === null) return;
        saliendo = true;
        ir(destino);
      },
    }),
    defaultOptions: {
      // … los mismos `queries` y `mutations` que hoy, con sus comentarios.
    },
  });
}

export function ProveedorDeDatos({ children }: { children: ReactNode }) {
  // (el docblock del useState, igual que hoy)
  const [cliente] = useState(() => crearClienteDeDatos());

  return <QueryClientProvider client={cliente}>{children}</QueryClientProvider>;
}
```
